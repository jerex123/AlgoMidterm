Sorting Algorithms Activity
Introduction

Ang program kay naggamit og Java to sort numbers. Naa ni tulo ka types sa sorting: Bubble Sort, Selection Sort, ug Insertion Sort. Ang ilang trabaho kay i-arrange ang mga numbers gikan sa gamay hangtod sa dako.

1. Bubble Sort

Ang Bubble Sort kay mag-compare sa duha ka number nga tapad. Kung mas dako ang first number, mag-switch sila og pwesto. Iyang balik-balikon hangtod maayo niya ang tanang numbers.

2. Selection Sort

Ang Selection Sort kay mangita og pinakagamay nga number ug ibutang niya sa pinakauna nga pwesto. Tapos mangita napud siya sa sunod nga pinakagamay nga number hangtod maayo niya ang tanang numbers.

3. Insertion Sort

Ang Insertion Sort kay mokuha og usa ka number tapos ibutang niya sa sakto nga pwesto. Kung naay mas dako nga number sa pinaka una, iyang ibalhin iyang ibutang ang number sa sakto nga arragement.

Differences Between the Three Sorting Algorithms

Ang Bubble Sort kay mag-compare niy nga numbers. Ang Selection Sort kay mangita sa pinakagamay nga number. Ang Insertion Sort kay magbutang sa number sa sakto nga pwesto. Lahi-lahi ilang pamaagi pero parehas ilang tumong nga maayos ang mga numbers.

Reflection Questions
1. How does each sorting algorithm arrange numbers? What makes their processes different?

Ang Bubble Sort kay mag-compare sa magtapad nga numbers. Ang Selection Sort kay mangita sa pinakagamay nga number. Ang Insertion Sort kay magbutang sa number sa sakto nga pwesto. Lahi-lahi ilang pamaagi sa paghan-ay sa mga numbers.

2. Among the three sorting algorithms, which one do you think is the easiest to understand and implement? Why?

Para nako, ang Bubble Sort ang pinakasayon sabton kay mag-compare ra siya sa duha ka numbers ug mag-switch og pwesto kung kinahanglan. Sayon ra sabton ug sundon ang iyang process.

3. If the numbers are already sorted, which algorithm do you think would perform better? Explain your answer based on how the algorithms work.

Para nako, ang Insertion Sort ang mas maayo kung sorted na daan ang mga numbers kay dili na kinahanglan magbalhin-balhin og daghang numbers. Mas gamay nalang iyang trabaho.

4. What will happen if you add more numbers to your array? How might this affect the performance of each sorting algorithm?

Kung magdugang kog daghang numbers sa array, mas modugay ang pag-sort kay mas daghan na silang i-check ug i-compare. Mas modaghan pud ilang trabaho.

5. As a future programmer, why is it important to understand different sorting algorithms instead of using just one?

Importante nga makat-on ta og lain-laing sorting algorithms kay makatabang ni sa atong programming. Dili tanan parehas og gamit, mao nga kinahanglan kabalo ta mopili kung unsay mas angay gamiton depende sa situation.
